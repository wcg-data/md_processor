关键问题：夜盘最后一个bar(oi=56458)到日盘第一个bar(oi=56447)之间
         的oi变化(-11手)去哪了？

答案：这个变化在集合竞价bar中被"重置"了，因为集合竞价bar是
     新交易时段的起点，oi_diff=0


三、为什么集合竞价bar的oi_diff=0？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

原因1：集合竞价是新时段的起点
  - 集合竞价期间没有"上一个bar"作为参考
  - 无法计算有意义的diff

原因2：跨时段的oi变化无法归因
  - 夜盘22:59 oi=56450
  - 休市期间（23:00-08:59）可能有:
    * 结算调整
    * 强制平仓
    * 系统调整
  - 日盘09:00 oi=56447
  - 这-3手的变化无法归因到任何一个bar

原因3：符合金融数据惯例
  - 第一个数据点的diff通常为0或NULL
  - 表示"从此刻开始观察"

五、5min聚合的oi_diff
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

输入：09:31-09:35的5个1min bar
┌─────────┬────┬─────────┐
│  时间   │ OI │ oi_diff │
├─────────┼────┼─────────┤
│ 09:31   │ 2  │  0      │  ← 修复后正确

      变化量 = 7-2 = 5 ✅ 正确！

如果第一个1min bar的oi_diff=2（错误值）：
  oi_diff = 2+1+1+3+0 = 7 ❌ 错误！
  (实际变化是5，不是7)


六、总结
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. OI是什么？
   → 市场瞬时持仓量，时点值，不是累计值

2. oi_diff是什么？
   → 当前bar的oi - 上一个bar的oi（差分）

3. 为什么第一个bar的oi_diff=0？
   → 因为没有"上一个bar"可以计算差分

4. 夜盘→日盘怎么处理？
   → 集合竞价bar的oi_diff=0（新时段起点）
   → 后续bar基于集合竞价的oi计算diff

5. 修复了什么bug？
   → 第一个bar的oi_diff从"oi本身"改为"0"

6. 为什么5min的oi_diff=sum(1min)?
   → 因为diff可以累加：
     (a-b) + (c-a) + (d-c) = d-b
     5个1min的diff之和 = 5min窗口的总变化
